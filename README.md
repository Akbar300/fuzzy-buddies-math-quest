# Fuzzy Buddies Math Quest

A visual, hands-on 3rd grade math adventure (Virginia SOL aligned): fractions, multiplication & division, place value, measurement, time, money, equations and data, with the Fuzzy Buddies as guides.

**Play it:** https://raw.githack.com/Akbar300/fuzzy-buddies-math-quest/main/index.html

GitHub Pages link: https://akbar300.github.io/fuzzy-buddies-math-quest/ (works once Pages is turned on for the main branch)

Tip: on a phone or tablet, open the link and use "Add to Home Screen" to launch it like an app. Progress is saved on the device.
